# Instrucțiuni pentru Codex — proiect PeLinie

## Context
Prototip static de interfață pentru transportul public din București. Punctul de intrare este `index.html`, cu CSS și JavaScript incluse direct, pentru publicare simplă pe GitHub Pages.

## Reguli de lucru
- Menține proiectul funcțional fără build, framework sau variabile de mediu până la decizia explicită de migrare.
- Nu prezenta date demonstrative drept informații verificate sau în timp real.
- Respectă accesibilitatea, compatibilitatea pe mobil și diacriticele limbii române.
- Nu introduce date personale, nume, fotografii ori localizarea individualizată a angajaților în raportări.
- Nu presupune că localStorage sincronizează date între utilizatori.
- Documentează în README fiecare schimbare care afectează rularea sau publicarea.

## Prima etapă după v0.1
Separă CSS și JavaScript în fișiere dedicate și adaugă teste ușoare pentru filtrare, raportare și expirarea datelor locale. Nu adăuga încă un backend fără o decizie explicită.
